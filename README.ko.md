## 소개

케이플레이어는 광고도, 군더더기도 없는 동영상·음악 플레이어입니다. 오픈소스 미디어 엔진 **libmpv** 를 바탕으로 만들어 코덱을 따로 설치하지 않아도 비디오 23종, 오디오 12종, 재생목록 3종, 모두 38가지 형식을 바로 재생합니다.

화면에는 영상만 있고, 마우스를 움직일 때만 아래쪽에 조작 버튼이 나타납니다. 파일을 창에 끌어다 놓으면 바로 재생되고, 드라마를 한 편 열면 같은 폴더의 다음 편이 차례대로 목록에 들어옵니다.

단축키와 마우스 동작은 모두 원하는 대로 바꿀 수 있고, 자막은 글꼴·색·외곽선·위치까지 세밀하게 꾸밀 수 있습니다.

## 주요 기능

- **38가지 형식** — MP4, MKV, AVI, MOV, WMV, WebM, TS, M2TS, VOB, RM/RMVB 등 비디오 23종, MP3, FLAC, AAC, M4A, WAV, OGG, Opus, WMA, APE, DSF 등 오디오 12종, 재생목록(M3U, M3U8, PLS) 3종.
- **코덱 설치 필요 없음** — 재생에 필요한 것이 모두 들어 있습니다.
- **하드웨어 가속** — 고해상도 영상도 부드럽게 재생합니다.
- **끌어다 놓기** — 본체 창에 놓으면 목록을 바꿔 바로 재생, 재생목록 창에 놓으면 목록에 추가합니다. 폴더를 놓으면 안의 미디어 파일만 골라 넣습니다.
- **다음 편 자동 추가** — 파일을 열면 같은 폴더의 연속된 파일(1화, 2화…)을 순서대로 목록에 넣습니다.
- **재생목록** — 끌어서 순서 바꾸기, 반복(전체·한 곡), 랜덤 재생, 종료 후에도 목록 기억.
- **자막** — 켜기/끄기, 트랙 전환, 글꼴·크기·색·굵게·외곽선·그림자·위치·정렬 설정, Windows 표시 언어에 맞춘 자막 언어 자동 선택.
- **재생 조작** — 챕터 이동, 프레임 단위 이동, 배속(0.25×–4.0×), 스크린샷(JPG/PNG).
- **정보 패널** — `TAB` 키로 파일·코덱·해상도·프레임·음성 정보를 한눈에.
- **음량 평준화** — 작은 소리와 큰 소리의 차이를 줄여 줍니다(강도 선택).
- **단축키·마우스 사용자 지정** — 동작 30가지의 키와 클릭·더블클릭·가운데 버튼·휠 동작을 원하는 대로.
- **파일 연결** — 환경설정에서 확장자별로 등록하고, Windows 기본 앱 선택 창을 바로 띄웁니다.
- **깔끔한 화면** — 테두리 없는 어두운 창, 항상 위, 창 위치·크기 기억.

## 사용법

### 처음 사용하기

1. 케이플레이어를 실행하면 가운데에 **케이플레이어 로고**가 있는 시작 화면이 나옵니다.
2. 동영상이나 음악 파일을 창에 끌어다 놓습니다. 로고를 클릭하거나 `Ctrl+O` 를 눌러 파일을 골라도 됩니다.
3. 바로 재생이 시작됩니다. 마우스를 움직이면 아래쪽에 조작 버튼이 나타나고, 잠시 가만히 두면 사라집니다.
4. `Space` 로 일시정지, `←` `→` 로 5초씩 이동, `↑` `↓` 로 음량을 조절합니다. `Enter` 나 더블클릭으로 전체 화면이 되고, `ESC` 로 돌아옵니다.
5. 오른쪽 아래의 재생목록 버튼으로 목록 창을, 그 옆 톱니바퀴 버튼으로 환경설정을 엽니다.

### 화면 구성

**재생 화면**

| 위치 | 역할 |
|---|---|
| 위쪽 막대 | 재생 중인 파일 이름. 오른쪽에 압정(항상 위) · 최소화 · 전체 화면 · 닫기 |
| 진행바 | 누르거나 끌어서 이동. 마우스를 올리면 그 지점의 시간이 말풍선으로 보이고, 챕터가 있으면 구분 표시가 나타남 |
| ⏮ ▶ ⏭ | 이전 파일 / 재생·일시정지 / 다음 파일 |
| 스피커 | 누르면 음소거. 마우스를 올리면 음량 막대가 펼쳐짐 |
| 시간 | 현재 위치 / 전체 길이 |
| 자막 | 자막 켜기/끄기 — 자막이 있는 파일에서만 나타남 |
| 톱니바퀴 | 환경설정 |
| 목록 | 재생목록 창 열기/닫기 |

창은 아무 곳이나 잡고 끌어서 옮기고, 가장자리를 잡아 크기를 바꿉니다. 음량이나 배속을 바꾸면 화면 가운데에 잠깐 표시됩니다.

**오른쪽 클릭 메뉴**

| 메뉴 | 역할 |
|---|---|
| 파일 열기 / 폴더 열기 | 파일이나 폴더를 골라 목록에 넣고 재생 |
| 화면 크기 | 영상 크기의 50% · 100% · 150% · 200%, 전체 화면, 꽉찬 화면 |
| 만든이 | 홈페이지 열기 |

**재생목록 창**

| 버튼 | 역할 |
|---|---|
| 반복 | 누를 때마다 반복 없음 → 전체 반복 → 한 곡 반복 |
| 랜덤 | 랜덤 재생 켜기/끄기 |
| + | 추가 — 파일 / 폴더 |
| − | 삭제 — 선택된 파일 / 선택 안 된 파일 / 전부 / 존재하지 않는 파일 |

항목을 더블클릭하면 재생하고, `Delete` 키는 선택한 항목을 목록에서 뺍니다(파일은 지우지 않습니다). 재생 중인 항목은 다른 색으로 표시됩니다.

### 이럴 때 이렇게

**드라마를 1화부터 차례로 보고 싶을 때**
한 편만 열면 됩니다. 케이플레이어는 같은 폴더에서 이름에 이어지는 번호가 있는 파일(`1화`·`2화`, `S01E01`·`S01E02` 등)을 찾아 번호 순서대로 목록에 넣습니다. `2화` 가 `10화` 보다 앞에 오도록 숫자 크기대로 정렬합니다. 3화를 열었다면 목록에는 1화부터 들어가지만 재생은 3화부터 시작합니다.
- 영상을 열면 같은 폴더의 음악 파일은 끼어들지 않습니다. 음악을 열면 영상이 끼어들지 않습니다.
- 폴더 안의 같은 종류 파일을 모두 넣고 싶으면 환경설정 → **일반 → 폴더 내 파일 자동 추가** 를 **모든 파일** 로, 연 파일 하나만 넣고 싶으면 **사용안함** 으로 바꿉니다.

**지금 목록을 버리고 새로 볼 때 / 목록 뒤에 덧붙일 때**
파일을 **본체 창**에 끌어다 놓으면 기존 목록을 비우고 놓은 파일로 바꿔 바로 재생합니다. **재생목록 창**에 놓으면 기존 목록은 그대로 두고 뒤에 덧붙인 뒤 추가한 첫 항목부터 재생합니다. 이미 목록에 있는 파일은 두 번 들어가지 않습니다.

**폴더째 넣고 싶을 때**
폴더를 끌어다 놓거나 오른쪽 클릭 → **폴더 열기** 를 고릅니다. 하위 폴더까지 뒤져 재생할 수 있는 파일만 목록에 넣습니다. 이미지·문서 같은 다른 파일은 알아서 걸러집니다.

**탐색기에서 파일을 여럿 골라 열 때**
탐색기에서 여러 파일을 선택하고 Enter를 누르면 이미 떠 있는 케이플레이어 한 창으로 모여, 첫 파일부터 재생되고 나머지는 목록에 들어갑니다. 이미 실행 중일 때의 동작은 환경설정 → **일반 → 이미 실행 중일 때** 에서 고릅니다.
- **실행 중인 창에서 재생** (기본) — 새로 연 파일을 떠 있는 창에서 바로 재생합니다.
- **실행 중인 창 목록에 추가** — 보던 영상은 그대로 두고 목록에만 추가합니다. 음악을 듣다가 곡을 모아 둘 때 편리합니다.
- **여러 개 실행 허용** — 파일마다 새 창을 엽니다. 두 영상을 나란히 비교할 때 씁니다.

**M3U·PLS 재생목록 파일을 열 때**
재생목록 파일을 열거나 끌어다 놓으면 파일 안에 적힌 곡들이 목록에 풀려 들어가고 첫 곡부터 재생됩니다. 재생목록 파일 위치를 기준으로 적힌 경로도, 메모장에서 저장한 한글 목록도 그대로 읽습니다.

**음악을 섞어 듣고 싶을 때**
재생목록 창의 **랜덤** 버튼을 켭니다. 목록을 한 바퀴 다 들을 때까지 같은 곡이 다시 나오지 않고, 한 바퀴를 돌면 다시 섞어 계속 재생합니다. 이전 버튼(⏮)을 누르면 실제로 들었던 순서대로 되돌아갑니다. 버튼에 마우스를 올리면 지금 모드가 설명으로 나옵니다.

**한 곡을 계속 반복하고 싶을 때 / 목록을 무한 반복할 때**
재생목록 창의 **반복** 버튼을 눌러 **한 곡 반복** 이나 **전체 반복** 으로 바꿉니다. 한 곡 반복은 랜덤이 켜져 있어도 우선합니다. 반복 없음이면 목록 끝에서 마지막 장면을 띄운 채 멈춥니다.

**목록 순서를 바꾸고 싶을 때**
항목을 잡고 위아래로 끌면 됩니다. `Ctrl`·`Shift` 로 여러 항목을 골라 한꺼번에 옮길 수도 있습니다. 목록 끝까지 끌면 알아서 스크롤됩니다.

**USB나 네트워크 드라이브의 파일을 목록에 넣어 둘 때**
파일이 있는 드라이브를 빼도 목록에서 사라지지 않고, 그 항목이 전체 경로로 표시됩니다. 재생할 차례가 되면 화면에 "파일을 찾을 수 없습니다" 알림을 잠깐 띄우고 다음 파일로 넘어갑니다. 드라이브를 다시 연결하면 표시가 알아서 원래대로 돌아옵니다. 정말 없어진 파일만 치우려면 목록 창의 **− → 존재하지 않는 파일** 을 누릅니다.

**다음에 켤 때 목록을 그대로 두고 싶을 때**
환경설정 → **일반 → 재생목록 저장** 이 켜져 있으면(기본) 종료할 때의 목록이 다음 실행에 그대로 돌아옵니다. 탐색기에서 파일을 더블클릭해 실행해도 지난 목록의 첫 곡이 아니라 그 파일이 재생됩니다. 매번 빈 목록으로 시작하고 싶으면 **사용안함** 으로 바꿉니다.

**자막을 켜고 싶을 때**
자막은 처음에 꺼져 있습니다. 자막이 있는 파일을 열면 아래쪽에 **자막 버튼**이 나타나니 눌러 켜거나 `V` 를 누르세요. 영상과 같은 이름의 자막 파일(`영화.srt`, `영화.ko.srt` 등)은 자동으로 불러옵니다.
- 자막을 늘 켜 두려면 환경설정 → **자막 → 자막 기본 표시** 를 **사용함** 으로.
- 자막 트랙이 여럿이면 `J` / `Shift+J` 로 바꿉니다.
- 트랙이 여럿인 MKV 는 Windows 표시 언어의 자막을 먼저 고르고, 없으면 영어 자막을 고릅니다. 원하는 언어가 따로 있으면 **기본 자막 언어** 칸에 `ja,jpn,en,eng` 처럼 원하는 순서로 적습니다.

**자막이 잘 안 보이거나 크기·위치를 바꾸고 싶을 때**
환경설정 → **자막** 에서 크기, 글꼴, 굵게, 글자색, 외곽선 두께·색, 그림자, 세로 위치, 정렬을 바꿉니다. 바꾸는 즉시 재생 화면에 반영되므로 보면서 맞추면 됩니다. 자막을 영상 아래쪽 검은 여백으로 내리려면 **세로 위치** 를 조절합니다.
노래방 자막처럼 효과와 스타일이 들어간 자막(ASS)은 **자막 파일 스타일 우선** 을 **사용함** 으로 두면 자막 파일이 정한 모양대로 나옵니다.

**강의·회의 영상을 빠르게 볼 때**
`C` 로 0.1배씩 빠르게, `X` 로 느리게, `]` / `[` 로 10%씩 바꾸고 `Z` 로 1.0배로 돌아옵니다. 0.25배부터 4배까지 되며, 바꿀 때마다 화면 가운데에 현재 배속이 잠깐 나옵니다.

**원하는 장면을 정확히 찾을 때**
`Shift+←` / `Shift+→` 는 1초씩 정확하게 이동하고, `,` / `.` 는 한 프레임씩 앞뒤로 움직입니다. 챕터가 있는 영상은 `Ctrl+←` / `Ctrl+→` 로 챕터를 건너뛰고, 진행바에서도 챕터 구분을 볼 수 있습니다.

**장면을 이미지로 남기고 싶을 때**
`S` 를 누르면 지금 장면이 **바탕화면**에 `영상.mp4-0001.jpg` 처럼 파일 이름에 번호가 붙어 저장됩니다. 저장할 폴더와 형식(JPG/PNG)은 환경설정 → **일반 → 스크린샷 폴더 / 형식** 에서 바꿉니다. 화질 손실 없이 남기려면 PNG 를 고릅니다.

**다른 일을 하면서 작은 창으로 볼 때**
위쪽 막대의 **압정** 버튼을 누르면 창이 항상 다른 창 위에 떠 있습니다(재생목록 창도 함께). 창을 원하는 크기로 줄여 화면 구석에 두면 됩니다. 오른쪽 클릭 → **화면 크기 → 50%** 로 영상 크기의 절반으로 바로 줄일 수도 있습니다.

**영상을 열 때 창 크기를 정하고 싶을 때**
환경설정 → **일반 → 재생 창 크기** 에서 고릅니다.
- **마지막 크기 유지** (기본) — 늘 쓰던 크기 그대로.
- **영상 크기에 맞춤** — 파일마다 영상 원래 크기로 창을 맞춥니다. 화면보다 크면 비율을 지켜 화면 안으로 줄입니다.
- **전체 화면** — 영상을 열면 바로 전체 화면으로 시작합니다.

창 위치와 크기는 종료 후에도 기억되고, 그 모니터를 떼어 냈다면 보이는 화면 안으로 옮겨 엽니다.

**화면비가 다른 영상을 여백 없이 꽉 채우고 싶을 때**
오른쪽 클릭 → **화면 크기 → 꽉찬 화면** 을 고르면 검은 여백 없이 모니터 전체로 늘립니다. 전체 화면을 끝내면 원래 비율로 돌아옵니다. 자주 쓴다면 환경설정 → **마우스** 에서 더블클릭을 **꽉찬 화면/원래 화면** 으로 바꿔 두세요.

**영상마다 소리 크기가 들쭉날쭉할 때**
**음량 평준화**가 기본으로 켜져 있어 작은 대사는 키우고 큰 효과음은 줄입니다. 차이를 더 줄이려면 환경설정 → **음성 → 평준화 강도** 를 **강하게**, 원음 그대로 들으려면 **음량 평준화 사용** 을 **사용안함** 으로 바꿉니다. 시작할 때의 음량은 **기본 볼륨** 에서 정합니다.
음소거 중에 음량을 올리면 음소거가 저절로 풀립니다.

**휠로 음량 대신 앞뒤로 이동하고 싶을 때 (마우스 동작 바꾸기)**
환경설정 → **마우스** 에서 왼쪽 버튼 한 번 클릭, 두 번 클릭, 가운데 버튼 클릭, 휠 위로, 휠 아래로 각각에 기능을 고릅니다. 예를 들어 휠을 **앞으로 이동 / 뒤로 이동** 으로, 한 번 클릭을 **재생/일시정지** 로, 가운데 버튼을 **다음 파일 재생** 으로 바꿀 수 있습니다.

**단축키를 손에 익은 키로 바꾸고 싶을 때**
환경설정 → **단축키** 에서 동작을 고른 뒤 아래 칸을 누르고 원하는 키(조합)를 누릅니다. **지우기** 로 키를 빼고, **단축키 기본값** 으로 처음 상태로 돌아갑니다. 기본 키가 없는 **재생목록**, **환경설정**, **항상 위** 에도 키를 줄 수 있습니다. 기본 단축키는 아래 표와 같습니다.

| 키 | 동작 |
|---|---|
| `Space` | 재생/일시정지 |
| `Enter` | 전체 화면 (`ESC` 로 해제) |
| `←` / `→` | 뒤로 / 앞으로 5초 |
| `Shift+←` / `Shift+→` | 뒤로 / 앞으로 1초 (정확) |
| `Ctrl+←` / `Ctrl+→` | 이전 / 다음 챕터 |
| `,` / `.` | 이전 / 다음 프레임 |
| `↑` / `↓` | 음량 +5 / −5 |
| `0` / `9` | 음량 +2 / −2 |
| `M` | 음소거 |
| `Page Up` / `Page Down` | 이전 / 다음 파일 |
| `V` | 자막 표시/숨김 |
| `J` / `Shift+J` | 다음 / 이전 자막 |
| `S` | 스크린샷 |
| `X` / `C` | 배속 −0.1 / +0.1 |
| `[` / `]` | 배속 −10% / +10% |
| `Z` | 배속 1.0x |
| `Ctrl+O` | 파일 열기 |
| `TAB` | 정보 패널 (고정) |

**파일 정보(코덱·해상도·비트레이트)를 보고 싶을 때**
재생 중에 `TAB` 을 누르면 파일 이름·형식·크기, 영상 코덱·해상도·프레임 수, 하드웨어 디코딩 여부, 음성 코덱·채널·샘플레이트, 자막 트랙, 음량이 한 화면에 나옵니다. 1초마다 새로 고쳐지고, 다시 `TAB` 을 누르면 닫힙니다.

**동영상 파일을 더블클릭하면 케이플레이어로 열리게 하고 싶을 때**
환경설정 → **연결** 에서 원하는 확장자를 체크합니다. **주요 파일** 을 누르면 많이 쓰는 형식만, **모두 선택** 을 누르면 38가지 전부 체크되며, 체크하는 즉시 등록됩니다. 케이플레이어가 등록한 파일에는 확장자별 아이콘이 붙습니다.
Windows 10·11 에서는 기본 앱을 사용자가 직접 골라야 하므로, 다른 프로그램이 기본 앱으로 지정된 확장자 옆에는 **[적용안됨]** 표시가 나옵니다. 그 표시를 누르면 Windows 의 기본 앱 선택 창이 바로 뜨니 케이플레이어를 고르면 됩니다. **Windows 기본 앱 설정 열기** 로 Windows 설정을 열어 한꺼번에 바꿀 수도 있습니다.
- 포터블 폴더를 다른 곳으로 옮겨도 다음 실행 때 연결이 새 위치로 맞춰집니다.
- 설치판을 제거하면 케이플레이어가 등록한 연결을 모두 원래대로 되돌립니다.

**설정을 처음 상태로 돌리고 싶을 때**
환경설정 아래의 **기본값 복원** 을 누르면 모든 설정과 단축키·마우스 동작이 기본값으로 돌아갑니다. 파일 연결은 바뀌지 않습니다.

**영상 출력을 그래픽 카드에 맞춰 조정하고 싶을 때**
환경설정 → **영상** 에서 **하드웨어 디코딩**(자동(안전) / 자동 / 사용 안 함), **출력 드라이버**, **그래픽 API**(자동 / Direct3D 11 / OpenGL / Vulkan), **화면 동기화**, **업스케일러**, **인터레이스 해제** 를 고릅니다. 대부분은 기본값이 가장 좋습니다. 이 카드의 설정은 케이플레이어를 다시 실행하면 적용됩니다.

## 설정

설정은 환경설정 창의 카드에서 바꾸며, 바꾸는 즉시 저장됩니다(**영상** 카드는 다시 실행하면 적용).

| 카드 | 항목 | 기본값 |
|---|---|---|
| 일반 | 반복 모드 · 랜덤 재생 | 반복 없음 · 사용안함 |
| | 재생목록 저장 | 사용함 |
| | 폴더 내 파일 자동 추가 | 관련 파일만 |
| | 이미 실행 중일 때 | 실행 중인 창에서 재생 |
| | 스크린샷 폴더 · 형식 | 바탕화면 · JPG |
| | 항상 위 | 사용안함 |
| | 재생 창 크기 | 마지막 크기 유지 |
| 영상 | 하드웨어 디코딩 · 출력 드라이버 · 그래픽 API · 화면 동기화 · 업스케일러 · 인터레이스 해제 | 자동(안전) · gpu · 자동 · 디스플레이 리샘플 · lanczos · 자동 |
| 음성 | 기본 볼륨 | 100 |
| | 음량 평준화 사용 · 평준화 강도 | 사용함 · 보통 |
| 자막 | 자막 기본 표시 | 사용안함 |
| | 자막 크기 · 기본 자막 언어 | 55 · Windows 표시 언어 + 영어 |
| | 글꼴 · 굵게 · 글자색 · 외곽선 두께 · 외곽선 색 · 그림자 · 세로 위치 · 정렬 | 기본 · 사용안함 · 흰색 · 3 · 검정 · 0 · 100 · 가운데 |
| | 자막 파일 스타일 우선 | 사용안함 |
| 연결 | 확장자별 등록 · 기본 앱 선택 | 설치판은 주요 파일 등록 |
| 단축키 | 동작 30가지의 키 | 위 표 |
| 마우스 | 한 번 클릭 · 두 번 클릭 · 가운데 버튼 · 휠 위로/아래로 | 아무 작동 안함 · 전체 화면/원래 화면 · 아무 작동 안함 · 볼륨 크게/작게 |

설정과 재생목록은 실행 파일과 같은 폴더에 저장되므로 포터블 폴더를 통째로 옮기면 그대로 따라갑니다.

화면 언어는 Windows 표시 언어를 따릅니다(한국어, 영어, 일본어, 중국어, 러시아어, 이탈리아어, 프랑스어, 스페인어, 아랍어 — 그 밖의 언어는 영어).

## 요구 사항

- Windows 10 또는 Windows 11, **64비트**
- 따로 설치할 코덱이나 구성 요소는 없습니다.
- 인터넷 연결은 새 버전 안내에만 씁니다.

## 업데이트

케이플레이어는 스스로 업데이트하지 **않습니다**. 실행할 때 새 버전이 있는지 확인해 안내 창을 띄우고, 받기로 하면 다운로드 페이지를 열고 프로그램을 닫습니다. 새 버전은 내부 검증을 거쳐 수동으로 배포되며 [케이플레이어 페이지](https://kilho.net/kplayer)에 공지됩니다. [업데이트 정책 안내](https://kilho.net/archives/notice/2940)를 참고하세요.

## 소스 빌드

소스는 [github.com/newkilho/KPlayer](https://github.com/newkilho/KPlayer) 에 공개되어 있습니다. [Lazarus](https://www.lazarus-ide.org/) 4.x (FPC 3.2.2, Win64) 로 만들며, 다음이 필요합니다.

- [LibMPVDelphi](https://github.com/nbuyer/libmpvdelphi) — libmpv 연결 유닛
- `laz.virtualtreeview_package` — Lazarus 에 들어 있는 Virtual Treeview 패키지
- 실행할 때 `KPlayer.exe` 옆에 `libmpv-2.dll`

`Const-sample.inc` 를 `Const.inc` 로 복사한 뒤 `lazbuild KPlayer.lpi` 로 빌드합니다. 다만 업데이트 확인·번역 등을 맡는 공용 라이브러리(klib)가 저장소 밖에 있어 저장소만으로는 실행 파일이 만들어지지 않습니다.
