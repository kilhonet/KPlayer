## 概要

KPlayer は、広告も余計なものもない動画・音楽プレーヤーです。オープンソースのメディアエンジン **libmpv** をもとに作られているため、コーデックを別途インストールしなくても、動画 23 種類、音声 12 種類、プレイリスト 3 種類、合わせて 38 種類の形式をすぐに再生できます。

画面には映像だけが表示され、マウスを動かしたときだけ下部に操作ボタンが現れます。ファイルをウィンドウにドロップするとすぐに再生が始まり、ドラマを 1 話開くと、同じフォルダーにある続きの話が順番にリストに追加されます。

ショートカットキーとマウス操作はすべて自由に変更でき、字幕はフォント・色・縁取り・位置まで細かく調整できます。

## 主な機能

- **38 種類の形式** — MP4, MKV, AVI, MOV, WMV, WebM, TS, M2TS, VOB, RM/RMVB など動画 23 種類、MP3, FLAC, AAC, M4A, WAV, OGG, Opus, WMA, APE, DSF など音声 12 種類、プレイリスト（M3U, M3U8, PLS）3 種類。
- **コーデックのインストール不要** — 再生に必要なものはすべて含まれています。
- **ハードウェアアクセラレーション** — 高解像度の動画も滑らかに再生します。
- **ドラッグ＆ドロップ** — 本体ウィンドウにドロップするとリストを置き換えてすぐに再生し、プレイリストウィンドウにドロップするとリストに追加します。フォルダーをドロップすると、中のメディアファイルだけを選んで追加します。
- **続きの話を自動追加** — ファイルを開くと、同じフォルダーにある連続したファイル（第1話、第2話…）を順番にリストに追加します。
- **プレイリスト** — ドラッグで並べ替え、リピート（全曲・1曲）、ランダム再生、終了後もリストを記憶。
- **字幕** — 表示/非表示、トラックの切り替え、フォント・サイズ・色・太字・縁取り・影・位置・配置の設定、Windows の表示言語に合わせた字幕言語の自動選択。
- **再生操作** — チャプター移動、フレーム単位の移動、再生速度（0.25×–4.0×）、スクリーンショット（JPG/PNG）。
- **情報パネル** — `TAB` キーでファイル・コーデック・解像度・フレーム・音声の情報をひと目で確認。
- **音量の平準化** — 小さな音と大きな音の差を縮めます（強さを選択可能）。
- **ショートカット・マウスのカスタマイズ** — 30 種類の操作のキーと、クリック・ダブルクリック・中ボタン・ホイールの動作を自由に設定。
- **ファイルの関連付け** — 環境設定で拡張子ごとに登録でき、Windows の既定のアプリ選択画面を直接開けます。
- **すっきりした画面** — 枠のない暗いウィンドウ、常に手前に表示、ウィンドウの位置・サイズを記憶。

## 使い方

### はじめての使い方

1. KPlayer を起動すると、中央に **KPlayer のロゴ**がある開始画面が表示されます。
2. 動画や音楽ファイルをウィンドウにドロップします。ロゴをクリックするか `Ctrl+O` を押してファイルを選ぶこともできます。
3. すぐに再生が始まります。マウスを動かすと下部に操作ボタンが現れ、しばらく動かさないと消えます。
4. `Space` で一時停止、`←` `→` で 5 秒ずつ移動、`↑` `↓` で音量を調整します。`Enter` かダブルクリックで全画面になり、`ESC` で元に戻ります。
5. 右下のプレイリストボタンでプレイリストウィンドウを、その隣の歯車ボタンで環境設定を開きます。

### 画面構成

**再生画面**

| 位置 | 役割 |
|---|---|
| 上部バー | 再生中のファイル名。右側に画びょう（常に手前に表示）· 最小化 · 全画面 · 閉じる |
| シークバー | クリックまたはドラッグで移動。マウスを乗せるとその位置の時間がツールチップで表示され、チャプターがあれば区切りが表示される |
| ⏮ ▶ ⏭ | 前のファイル / 再生・一時停止 / 次のファイル |
| スピーカー | クリックでミュート。マウスを乗せると音量バーが開く |
| 時間 | 現在の位置 / 全体の長さ |
| 字幕 | 字幕の表示/非表示 — 字幕のあるファイルでのみ表示 |
| 歯車 | 環境設定 |
| リスト | プレイリストウィンドウを開く/閉じる |

ウィンドウはどこをつかんでもドラッグで移動でき、端をつかむとサイズを変えられます。音量や再生速度を変えると、画面の中央にしばらく表示されます。

**右クリックメニュー**

| メニュー | 役割 |
|---|---|
| ファイルを開く / フォルダーを開く | ファイルやフォルダーを選んでリストに追加し、再生 |
| 画面サイズ | 動画サイズの 50% · 100% · 150% · 200%、全画面、全画面 (引き伸ばし) |
| 製作者 オ・キルホ | ウェブサイトを開く |

**プレイリストウィンドウ**

| ボタン | 役割 |
|---|---|
| リピート | 押すたびに リピートなし → 全曲リピート → 1曲リピート |
| ランダム | ランダム再生のオン/オフ |
| + | 追加 — ファイル / フォルダー |
| − | 削除 — 選択したファイル / 選択していないファイル / すべて / 存在しないファイル |

項目をダブルクリックすると再生し、`Delete` キーで選択した項目をリストから外します（ファイル自体は削除されません）。再生中の項目は別の色で表示されます。

### こんなときは

**ドラマを第1話から順番に見たい**
1 話だけ開けば十分です。KPlayer は同じフォルダーから、名前に続き番号のあるファイル（`第1話`·`第2話`、`S01E01`·`S01E02` など）を探して番号順にリストに追加します。`2話` が `10話` より前に来るよう、数の大きさで並べます。第3話を開いた場合、リストには第1話から入りますが、再生は第3話から始まります。
- 動画を開いたとき、同じフォルダーの音楽ファイルは入りません。音楽を開いたときは動画が入りません。
- フォルダー内の同じ種類のファイルをすべて追加したいときは環境設定 → **一般 → フォルダー内のファイルを自動追加** を **すべてのファイル** に、開いたファイル 1 つだけにしたいときは **オフ** に変更します。

**今のリストを捨てて新しく見る / リストの後ろに追加する**
ファイルを**本体ウィンドウ**にドロップすると、既存のリストを空にしてドロップしたファイルに置き換え、すぐに再生します。**プレイリストウィンドウ**にドロップすると、既存のリストはそのままで後ろに追加し、追加した最初の項目から再生します。すでにリストにあるファイルが二重に入ることはありません。

**フォルダーごと追加したい**
フォルダーをドロップするか、右クリック → **フォルダーを開く** を選びます。サブフォルダーまで探して、再生できるファイルだけをリストに追加します。画像や文書などのほかのファイルは自動的に除外されます。

**エクスプローラーで複数のファイルを選んで開く**
エクスプローラーで複数のファイルを選んで Enter を押すと、すでに開いている KPlayer の 1 つのウィンドウにまとめられ、最初のファイルから再生されて残りはリストに入ります。既に実行中のときの動作は、環境設定 → **一般 → 既に実行中の場合** で選びます。
- **実行中のウィンドウで再生**（既定）— 新しく開いたファイルを、開いているウィンドウですぐに再生します。
- **実行中のプレイリストに追加** — 見ていた動画はそのままで、リストにだけ追加します。音楽を聴きながら曲を集めるときに便利です。
- **複数起動を許可** — ファイルごとに新しいウィンドウを開きます。2 つの動画を並べて比べるときに使います。

**M3U・PLS のプレイリストファイルを開く**
プレイリストファイルを開くかドロップすると、ファイルに書かれた曲がリストに展開され、最初の曲から再生されます。プレイリストファイルの場所を基準にした相対パスも、メモ帳で保存した日本語のリストもそのまま読み込めます。

**音楽をシャッフルして聴きたい**
プレイリストウィンドウの **ランダム** ボタンをオンにします。リストを一巡するまで同じ曲は流れず、一巡すると再びシャッフルして再生を続けます。前へボタン（⏮）を押すと、実際に聴いた順にさかのぼります。ボタンにマウスを乗せると、現在のモードの説明が表示されます。

**1 曲をずっとリピートしたい / リストを繰り返し再生したい**
プレイリストウィンドウの **リピート** ボタンを押して **1曲リピート** か **全曲リピート** に切り替えます。1曲リピートはランダムがオンでも優先されます。リピートなしの場合は、リストの最後で最後の場面を表示したまま停止します。

**リストの順番を変えたい**
項目をつかんで上下にドラッグします。`Ctrl`・`Shift` で複数の項目を選んでまとめて移動することもできます。リストの端までドラッグすると自動的にスクロールします。

**USB メモリーやネットワークドライブのファイルをリストに入れておく**
ファイルのあるドライブを外してもリストからは消えず、その項目はフルパスで表示されます。再生の順番が来ると、画面に「ファイルが見つかりません」という通知をしばらく表示して次のファイルに進みます。ドライブをもう一度接続すると、表示は自動的に元に戻ります。本当になくなったファイルだけを片付けるには、プレイリストウィンドウの **− → 存在しないファイル** を押します。

**次回起動時もリストをそのまま残したい**
環境設定 → **一般 → プレイリストの保存** がオン（既定）なら、終了したときのリストが次回の起動時にそのまま戻ります。エクスプローラーでファイルをダブルクリックして起動しても、前回のリストの最初の曲ではなくそのファイルが再生されます。毎回空のリストで始めたいときは **オフ** に変更します。

**字幕を表示したい**
字幕は最初はオフになっています。字幕のあるファイルを開くと下部に**字幕ボタン**が現れるので、押してオンにするか `V` を押してください。動画と同じ名前の字幕ファイル（`映画.srt`、`映画.ja.srt` など）は自動的に読み込まれます。
- 字幕を常に表示するには、環境設定 → **字幕 → 字幕を既定で表示** を **オン** に。
- 字幕トラックが複数ある場合は `J` / `Shift+J` で切り替えます。
- トラックが複数ある MKV では、Windows の表示言語の字幕を優先し、なければ英語の字幕を選びます。ほかに希望の言語があれば、**既定の字幕言語** 欄に `ja,jpn,en,eng` のように希望の順に入力します。

**字幕が見づらい、またはサイズや位置を変えたい**
環境設定 → **字幕** で、サイズ、フォント、太字、文字色、縁取りの太さ・色、影、縦位置、配置を変更します。変更はすぐに再生画面に反映されるので、見ながら調整できます。字幕を動画の下の黒い余白に下げたいときは **縦位置** を調整します。
カラオケ字幕のようにエフェクトやスタイルの入った字幕（ASS）は、**字幕ファイルのスタイルを優先** を **オン** にすると、字幕ファイルが指定したとおりの見た目で表示されます。

**講義や会議の動画を速く見たい**
`C` で 0.1 倍ずつ速く、`X` で遅く、`]` / `[` で 10% ずつ変更し、`Z` で 1.0 倍に戻ります。0.25 倍から 4 倍まで設定でき、変更するたびに画面の中央に現在の速度がしばらく表示されます。

**見たい場面を正確に探したい**
`Shift+←` / `Shift+→` は 1 秒ずつ正確に移動し、`,` / `.` は 1 フレームずつ前後に移動します。チャプターのある動画は `Ctrl+←` / `Ctrl+→` でチャプターを移動でき、シークバーでもチャプターの区切りを確認できます。

**場面を画像として保存したい**
`S` を押すと、今の場面が**デスクトップ**に `動画.mp4-0001.jpg` のようにファイル名に番号を付けて保存されます。保存先フォルダーと形式（JPG/PNG）は、環境設定 → **一般 → スクリーンショットのフォルダー / 形式** で変更します。画質を落とさずに保存するには PNG を選びます。

**作業をしながら小さなウィンドウで見たい**
上部バーの **画びょう** ボタンを押すと、ウィンドウが常にほかのウィンドウより手前に表示されます（プレイリストウィンドウも一緒に）。ウィンドウを好きなサイズに縮めて画面の隅に置いてください。右クリック → **画面サイズ → 50%** で動画サイズの半分にすぐ縮めることもできます。

**動画を開いたときのウィンドウサイズを決めたい**
環境設定 → **一般 → 再生時のウィンドウサイズ** で選びます。
- **前回のサイズを維持**（既定）— いつも使っているサイズのまま。
- **動画サイズに合わせる** — ファイルごとに動画の元のサイズにウィンドウを合わせます。画面より大きい場合は、縦横比を保ったまま画面内に収まるよう縮めます。
- **全画面** — 動画を開くとすぐに全画面で始まります。

ウィンドウの位置とサイズは終了後も記憶され、そのモニターを取り外した場合は、見える画面内に移して開きます。

**縦横比の違う動画を余白なしで画面いっぱいに表示したい**
右クリック → **画面サイズ → 全画面 (引き伸ばし)** を選ぶと、黒い余白なしでモニター全体に引き伸ばします。全画面を終えると元の比率に戻ります。よく使うなら、環境設定 → **マウス** でダブルクリックを **全画面(引き伸ばし)/元のサイズ** に変えておきましょう。

**動画ごとに音量がばらばらなとき**
**音量の平準化**が既定でオンになっており、小さなセリフは大きく、大きな効果音は小さくします。差をさらに縮めるには環境設定 → **音声 → 平準化の強さ** を **強め** に、元の音のまま聴くには **音量の平準化を使用** を **オフ** に変更します。起動時の音量は **既定の音量** で決めます。
ミュート中に音量を上げると、ミュートは自動的に解除されます。

**ホイールで音量の代わりに前後へ移動したい（マウス操作の変更）**
環境設定 → **マウス** で、左ボタン シングルクリック、左ボタン ダブルクリック、中ボタン クリック、ホイール上、ホイール下のそれぞれに機能を選びます。たとえばホイールを **前方へ移動 / 後方へ移動** に、シングルクリックを **再生/一時停止** に、中ボタンを **次のファイルを再生** に変更できます。

**ショートカットキーを使い慣れたキーに変えたい**
環境設定 → **ショートカット** で操作を選び、下の欄をクリックして希望のキー（組み合わせ）を押します。**クリア** でキーを外し、**ショートカットを初期化** で最初の状態に戻ります。既定のキーがない **プレイリスト**、**環境設定**、**常に手前に表示** にもキーを割り当てられます。既定のショートカットは次の表のとおりです。

| キー | 操作 |
|---|---|
| `Space` | 再生/一時停止 |
| `Enter` | 全画面（`ESC` で解除） |
| `←` / `→` | 5秒戻る / 5秒進む |
| `Shift+←` / `Shift+→` | 1秒戻る (正確) / 1秒進む (正確) |
| `Ctrl+←` / `Ctrl+→` | 前のチャプター / 次のチャプター |
| `,` / `.` | 前のフレーム / 次のフレーム |
| `↑` / `↓` | 音量 +5 / −5 |
| `0` / `9` | 音量 +2 / −2 |
| `M` | ミュート |
| `Page Up` / `Page Down` | 前のファイル / 次のファイル |
| `V` | 字幕の表示/非表示 |
| `J` / `Shift+J` | 次の字幕トラック / 前の字幕トラック |
| `S` | スクリーンショット |
| `X` / `C` | 速度 −0.1 / +0.1 |
| `[` / `]` | 速度 −10% / +10% |
| `Z` | 速度 1.0x |
| `Ctrl+O` | ファイルを開く |
| `TAB` | 情報パネル（固定） |

**ファイルの情報（コーデック・解像度・ビットレート）を見たい**
再生中に `TAB` を押すと、ファイル名・形式・サイズ、映像のコーデック・解像度・フレームレート、ハードウェアデコードの使用有無、音声のコーデック・チャンネル・サンプルレート、字幕トラック、音量が 1 つの画面に表示されます。1 秒ごとに更新され、もう一度 `TAB` を押すと閉じます。

**動画ファイルをダブルクリックしたら KPlayer で開くようにしたい**
環境設定 → **関連付け** で希望の拡張子にチェックを入れます。**主なファイル** を押すとよく使う形式だけが、**すべて選択** を押すと 38 種類すべてがチェックされ、チェックした時点で登録されます。KPlayer が登録したファイルには拡張子ごとのアイコンが付きます。
Windows 10・11 では既定のアプリをユーザーが自分で選ぶ必要があるため、ほかのプログラムが既定のアプリになっている拡張子の横には **[未適用]** と表示されます。その表示をクリックすると Windows の既定のアプリ選択画面がすぐに開くので、KPlayer を選んでください。**Windows の既定のアプリ設定を開く** で Windows の設定を開き、まとめて変更することもできます。
- ポータブルのフォルダーを別の場所に移しても、次回起動時に関連付けが新しい場所に合わせられます。
- インストーラー版をアンインストールすると、KPlayer が登録した関連付けはすべて元に戻ります。

**設定を最初の状態に戻したい**
環境設定の下部にある **既定値** を押すと、すべての設定とショートカット・マウス操作が既定値に戻ります。ファイルの関連付けは変更されません。

**映像出力をグラフィックカードに合わせて調整したい**
環境設定 → **映像** で、**ハードウェアデコード**（自動(安全) / 自動 / 使用しない）、**出力ドライバー**、**グラフィック API**（自動 / Direct3D 11 / OpenGL / Vulkan）、**画面同期**、**アップスケーラー**、**インターレース解除** を選びます。ほとんどの場合は既定値が最適です。このカードの設定は KPlayer を再起動すると適用されます。

## 設定

設定は環境設定ウィンドウのカードで変更し、変更はすぐに保存されます（**映像** カードは再起動すると適用）。

| カード | 項目 | 既定値 |
|---|---|---|
| 一般 | リピートモード · ランダム再生 | リピートなし · オフ |
| | プレイリストの保存 | オン |
| | フォルダー内のファイルを自動追加 | 関連ファイルのみ |
| | 既に実行中の場合 | 実行中のウィンドウで再生 |
| | スクリーンショットのフォルダー · 形式 | デスクトップ · JPG |
| | 常に手前に表示 | オフ |
| | 再生時のウィンドウサイズ | 前回のサイズを維持 |
| 映像 | ハードウェアデコード · 出力ドライバー · グラフィック API · 画面同期 · アップスケーラー · インターレース解除 | 自動(安全) · gpu · 自動 · ディスプレイリサンプル · lanczos · 自動 |
| 音声 | 既定の音量 | 100 |
| | 音量の平準化を使用 · 平準化の強さ | オン · 標準 |
| 字幕 | 字幕を既定で表示 | オフ |
| | 字幕サイズ · 既定の字幕言語 | 55 · Windows の表示言語 + 英語 |
| | フォント · 太字 · 文字色 · 縁取りの太さ · 縁取りの色 · 影 · 縦位置 · 配置 | (既定) · オフ · 白 · 3 · 黒 · 0 · 100 · 中央 |
| | 字幕ファイルのスタイルを優先 | オフ |
| 関連付け | 拡張子ごとの登録 · 既定のアプリの選択 | インストーラー版は主なファイルを登録 |
| ショートカット | 30 種類の操作のキー | 上の表 |
| マウス | シングルクリック · ダブルクリック · 中ボタン · ホイール上/下 | 何もしない · 全画面/元のサイズ · 何もしない · 音量を上げる/下げる |

設定とプレイリストは実行ファイルと同じフォルダーに保存されるので、ポータブルのフォルダーを丸ごと移せばそのまま引き継がれます。

画面の言語は Windows の表示言語に従います（韓国語、英語、日本語、中国語、ロシア語、イタリア語、フランス語、スペイン語、アラビア語 — それ以外の言語は英語）。

## 動作環境

- Windows 10 または Windows 11、**64 ビット**
- 別途インストールするコーデックやコンポーネントはありません。
- インターネット接続は新しいバージョンの案内にだけ使います。

## 更新

KPlayer は自動更新を**行いません**。起動時に新しいバージョンがあるか確認して案内画面を表示し、入手を選ぶとダウンロードページを開いてプログラムを終了します。新しいバージョンは内部検証を経て手動で配布され、[KPlayer ページ](https://kilho.net/kplayer)で告知されます。[更新ポリシーのお知らせ](https://en.kilho.net/archives/notice/2940)もご覧ください。

## ソースからのビルド

ソースは [github.com/newkilho/KPlayer](https://github.com/newkilho/KPlayer) で公開されています。[Lazarus](https://www.lazarus-ide.org/) 4.x（FPC 3.2.2, Win64）でビルドし、次のものが必要です。

- [LibMPVDelphi](https://github.com/nbuyer/libmpvdelphi) — libmpv の接続ユニット
- `laz.virtualtreeview_package` — Lazarus に含まれている Virtual Treeview パッケージ
- 実行時に `KPlayer.exe` の隣に `libmpv-2.dll`

`Const-sample.inc` を `Const.inc` にコピーしてから `lazbuild KPlayer.lpi` でビルドします。ただし、更新確認や翻訳などを担う共用ライブラリ（klib）がリポジトリ外にあるため、リポジトリだけでは実行ファイルは作れません。
