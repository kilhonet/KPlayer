## 概述

KPlayer 是一款没有广告、没有多余功能的视频和音乐播放器。它基于开源媒体引擎 **libmpv** 打造，无需另外安装解码器，即可直接播放 23 种视频、12 种音频、3 种播放列表，共 38 种格式。

画面上只有视频，只有移动鼠标时下方才会出现控制按钮。把文件拖进窗口就会立即播放；打开电视剧的一集后，同一文件夹中的后续剧集会按顺序加入列表。

所有快捷键和鼠标操作都可以随意更改，字幕也可以细致地调整字体、颜色、描边和位置。

## 主要功能

- **38 种格式** — MP4、MKV、AVI、MOV、WMV、WebM、TS、M2TS、VOB、RM/RMVB 等 23 种视频格式，MP3、FLAC、AAC、M4A、WAV、OGG、Opus、WMA、APE、DSF 等 12 种音频格式，以及 3 种播放列表格式（M3U、M3U8、PLS）。
- **无需安装解码器** — 播放所需的一切都已内置。
- **硬件加速** — 高分辨率视频也能流畅播放。
- **拖放** — 拖到主窗口会替换列表并立即播放，拖到播放列表窗口则添加到列表中。拖入文件夹时只会挑出其中的媒体文件。
- **自动添加后续剧集** — 打开文件时，会把同一文件夹中的连续文件（第1集、第2集…）按顺序加入列表。
- **播放列表** — 拖动调整顺序、重复（全部 · 单曲）、随机播放，关闭程序后仍会记住列表。
- **字幕** — 显示/隐藏、切换字幕轨，设置字体 · 大小 · 颜色 · 粗体 · 描边 · 阴影 · 位置 · 对齐，并根据 Windows 显示语言自动选择字幕语言。
- **播放控制** — 章节跳转、逐帧移动、倍速（0.25×–4.0×）、截图（JPG/PNG）。
- **信息面板** — 按 `TAB` 键即可一览文件、解码器、分辨率、帧和音频信息。
- **音量标准化** — 缩小轻声与大声之间的差距（可选强度）。
- **自定义快捷键和鼠标** — 可随意设置 30 种操作的按键，以及单击、双击、中键和滚轮的功能。
- **文件关联** — 在设置中按扩展名逐个注册，并可直接打开 Windows 默认应用选择窗口。
- **简洁的界面** — 无边框深色窗口、总在最前、记住窗口位置和大小。

## 使用方法

### 快速上手

1. 启动 KPlayer 后，会出现中间带有 **KPlayer 徽标**的开始画面。
2. 把视频或音乐文件拖进窗口。也可以点击徽标或按 `Ctrl+O` 选择文件。
3. 播放会立即开始。移动鼠标时下方会出现控制按钮，鼠标静止片刻后按钮会消失。
4. 按 `Space` 暂停，`←` `→` 每次移动 5 秒，`↑` `↓` 调节音量。按 `Enter` 或双击进入全屏，按 `ESC` 返回。
5. 右下角的播放列表按钮可打开列表窗口，旁边的齿轮按钮可打开设置。

### 窗口布局

**播放画面**

| 位置 | 作用 |
|---|---|
| 顶部栏 | 正在播放的文件名。右侧依次为图钉（总在最前） · 最小化 · 全屏 · 关闭 |
| 进度条 | 点击或拖动以跳转。鼠标悬停时会以提示框显示该位置的时间；有章节时会显示章节分隔标记 |
| ⏮ ▶ ⏭ | 上一个文件 / 播放·暂停 / 下一个文件 |
| 扬声器 | 点击静音。鼠标悬停时会展开音量条 |
| 时间 | 当前位置 / 总时长 |
| 字幕 | 显示/隐藏字幕 — 仅在有字幕的文件中出现 |
| 齿轮 | 设置 |
| 列表 | 打开/关闭播放列表窗口 |

按住窗口任意位置即可拖动移动，拖动边缘可调整大小。更改音量或倍速时，画面中央会短暂显示当前值。

**右键菜单**

| 菜单 | 作用 |
|---|---|
| 打开文件 / 打开文件夹 | 选择文件或文件夹，加入列表并播放 |
| 画面大小 | 视频尺寸的 50% · 100% · 150% · 200%、全屏、全屏 (拉伸) |
| 作者 吴吉浩 | 打开网站 |

**播放列表窗口**

| 按钮 | 作用 |
|---|---|
| 重复 | 每按一次依次切换：不重复 → 全部重复 → 单曲重复 |
| 随机播放 | 开启/关闭随机播放 |
| + | 添加 — 文件 / 文件夹 |
| − | 删除 — 选中的文件 / 未选中的文件 / 全部 / 不存在的文件 |

双击项目即可播放；按 `Delete` 键会把选中的项目从列表中移除（不会删除文件本身）。正在播放的项目会以不同颜色显示。

### 遇到这些情况时

**想从第 1 集开始按顺序看电视剧**
只需打开其中一集。KPlayer 会在同一文件夹中查找文件名带有连续编号的文件（`第1集`·`第2集`、`S01E01`·`S01E02` 等），并按编号顺序加入列表。排序按数字大小进行，因此 `第2集` 会排在 `第10集` 前面。如果打开的是第 3 集，列表会从第 1 集开始，但播放从第 3 集开始。
- 打开视频时，同一文件夹中的音乐文件不会混进来；打开音乐时，视频也不会混进来。
- 若想加入文件夹中所有同类文件，请把设置 → **常规 → 自动添加文件夹中的文件** 改为 **所有文件**；若只想加入打开的那一个文件，请改为 **关闭**。

**丢掉当前列表重新开始 / 添加到列表末尾**
把文件拖到**主窗口**，会清空现有列表，换成拖入的文件并立即播放。拖到**播放列表窗口**，则保留现有列表，把文件添加到末尾，并从添加的第一个项目开始播放。已在列表中的文件不会重复加入。

**想整个文件夹一起加入**
把文件夹拖进窗口，或选择右键 → **打开文件夹**。KPlayer 会连同子文件夹一起查找，只把可以播放的文件加入列表。图片、文档等其他文件会被自动过滤掉。

**在资源管理器中选择多个文件打开**
在资源管理器中选中多个文件并按 Enter，它们会汇集到已打开的同一个 KPlayer 窗口中，从第一个文件开始播放，其余文件加入列表。KPlayer 已在运行时的行为可在设置 → **常规 → 已在运行时** 中选择。
- **在运行中的窗口播放**（默认） — 在已打开的窗口中立即播放新打开的文件。
- **添加到运行中的播放列表** — 正在看的视频继续播放，只把文件加入列表。适合一边听音乐一边收集歌曲。
- **允许多个实例** — 每个文件都打开一个新窗口。适合把两个视频并排比较。

**打开 M3U · PLS 播放列表文件**
打开或拖入播放列表文件后，文件中列出的曲目会展开加入列表，并从第一首开始播放。以播放列表文件位置为基准写的相对路径，以及用记事本保存的含中文等非英文名称的列表，都能正常读取。

**想随机播放音乐**
开启播放列表窗口中的 **随机播放** 按钮。在整个列表播完一轮之前不会重复播放同一首，播完一轮后会重新打乱继续播放。按上一个按钮（⏮）会按实际听过的顺序往回退。把鼠标悬停在按钮上，会显示当前模式的说明。

**想单曲循环 / 无限循环整个列表**
点击播放列表窗口中的 **重复** 按钮，切换为 **单曲重复** 或 **全部重复**。即使开启了随机播放，单曲重复也优先。设为不重复时，播放到列表末尾会停在最后一个画面上。

**想调整列表顺序**
按住项目上下拖动即可。也可以用 `Ctrl` · `Shift` 选择多个项目一起移动。拖到列表边缘时会自动滚动。

**把 U 盘或网络驱动器中的文件留在列表里**
即使拔掉文件所在的驱动器，文件也不会从列表中消失，而是以完整路径显示。轮到播放时，画面上会短暂显示"找不到文件"提示，然后跳到下一个文件。重新连接驱动器后，显示会自动恢复原样。若只想清除真正已不存在的文件，请点击列表窗口的 **− → 不存在的文件**。

**下次启动时保留列表**
设置 → **常规 → 保存播放列表** 为开启时（默认），退出时的列表会在下次启动时原样恢复。即使在资源管理器中双击文件启动，播放的也是该文件，而不是旧列表的第一首。若想每次都从空列表开始，请改为 **关闭**。

**想开启字幕**
字幕一开始是关闭的。打开带字幕的文件后，下方会出现 **字幕按钮**，点击它或按 `V` 即可开启。与视频同名的字幕文件（`电影.srt`、`电影.zh.srt` 等）会自动加载。
- 若想始终显示字幕，请把设置 → **字幕 → 默认显示字幕** 改为 **开启**。
- 有多条字幕轨时，用 `J` / `Shift+J` 切换。
- 对于有多条字幕轨的 MKV，会优先选择 Windows 显示语言的字幕，没有时选择英文字幕。若有其他想要的语言，请在 **默认字幕语言** 栏中按优先顺序填写，例如 `ja,jpn,en,eng`。

**字幕看不清，或想更改大小和位置**
在设置 → **字幕** 中可以更改大小、字体、粗体、文字颜色、描边宽度和颜色、阴影、垂直位置和对齐。更改会立即反映在播放画面上，可以边看边调。若想把字幕移到视频下方的黑边中，请调整 **垂直位置**。
像卡拉 OK 字幕那样带有特效和样式的字幕（ASS），把 **优先使用字幕文件样式** 设为 **开启**，就会按字幕文件指定的样式显示。

**快速观看讲座或会议视频**
按 `C` 每次加快 0.1 倍，按 `X` 减慢，按 `]` / `[` 每次改变 10%，按 `Z` 恢复 1.0 倍。范围为 0.25 倍到 4 倍，每次更改时画面中央都会短暂显示当前倍速。

**精确查找想要的画面**
`Shift+←` / `Shift+→` 精确移动 1 秒，`,` / `.` 前后逐帧移动。有章节的视频可用 `Ctrl+←` / `Ctrl+→` 跳转章节，进度条上也能看到章节分隔。

**想把画面保存为图片**
按 `S`，当前画面会保存到**桌面**，文件名后附加编号，如 `视频.mp4-0001.jpg`。保存的文件夹和格式（JPG/PNG）可在设置 → **常规 → 截图文件夹 / 格式** 中更改。若想无损保存，请选择 PNG。

**一边做别的事一边用小窗口观看**
点击顶部栏的 **图钉** 按钮，窗口会始终显示在其他窗口之上（播放列表窗口也一样）。把窗口缩小到合适大小放在屏幕角落即可。也可以选择右键 → **画面大小 → 50%**，一步缩小到视频尺寸的一半。

**想指定打开视频时的窗口大小**
在设置 → **常规 → 播放时窗口大小** 中选择。
- **保持上次大小**（默认） — 保持平时使用的大小。
- **适应视频大小** — 按每个视频的原始尺寸调整窗口。若比屏幕大，会保持比例缩小到屏幕内。
- **全屏** — 打开视频后直接以全屏开始。

窗口位置和大小在退出后也会被记住；如果那台显示器已断开，会移到可见的屏幕内打开。

**想让不同画面比例的视频无黑边铺满屏幕**
选择右键 → **画面大小 → 全屏 (拉伸)**，视频会拉伸到整个显示器，没有黑边。退出全屏后恢复原始比例。如果经常使用，可以在设置 → **鼠标** 中把双击改为 **拉伸全屏/还原**。

**各视频音量忽大忽小**
**音量标准化** 默认开启，会放大轻声对白、压低响亮音效。若想进一步缩小差距，请把设置 → **音频 → 标准化强度** 改为 **强**；若想听原始声音，请把 **使用音量标准化** 改为 **关闭**。启动时的音量在 **默认音量** 中设置。
静音时调高音量会自动取消静音。

**想用滚轮前后跳转而不是调节音量（更改鼠标操作）**
在设置 → **鼠标** 中，可以分别为左键单击、左键双击、中键单击、滚轮向上、滚轮向下选择功能。例如，可以把滚轮设为 **快进 / 快退**，把单击设为 **播放/暂停**，把中键设为 **播放下一个文件**。

**想把快捷键改成顺手的按键**
在设置 → **快捷键** 中选择操作，点击下方输入框，然后按下想要的按键（组合）。**清除** 可移除按键，**默认快捷键** 可恢复初始状态。没有默认按键的 **播放列表**、**设置**、**总在最前** 也可以分配按键。默认快捷键如下表。

| 按键 | 操作 |
|---|---|
| `Space` | 播放/暂停 |
| `Enter` | 全屏（按 `ESC` 退出） |
| `←` / `→` | 后退 5 秒 / 前进 5 秒 |
| `Shift+←` / `Shift+→` | 后退 1 秒 (精确) / 前进 1 秒 (精确) |
| `Ctrl+←` / `Ctrl+→` | 上一章节 / 下一章节 |
| `,` / `.` | 上一帧 / 下一帧 |
| `↑` / `↓` | 音量 +5 / −5 |
| `0` / `9` | 音量 +2 / −2 |
| `M` | 静音 |
| `Page Up` / `Page Down` | 上一个文件 / 下一个文件 |
| `V` | 显示/隐藏字幕 |
| `J` / `Shift+J` | 下一字幕轨 / 上一字幕轨 |
| `S` | 截图 |
| `X` / `C` | 速度 −0.1 / +0.1 |
| `[` / `]` | 速度 −10% / +10% |
| `Z` | 速度 1.0x |
| `Ctrl+O` | 打开文件 |
| `TAB` | 信息面板（固定） |

**想查看文件信息（解码器 · 分辨率 · 比特率）**
播放时按 `TAB`，文件名 · 格式 · 大小，视频解码器 · 分辨率 · 帧率，是否使用硬件解码，音频解码器 · 声道 · 采样率，字幕轨和音量会显示在同一个画面上。信息每秒刷新一次，再按一次 `TAB` 即可关闭。

**想让双击视频文件时用 KPlayer 打开**
在设置 → **文件关联** 中勾选想要的扩展名。点击 **常用类型** 只勾选常用格式，点击 **全选** 则勾选全部 38 种，勾选后立即注册。由 KPlayer 注册的文件会带有对应扩展名的图标。
在 Windows 10 · 11 中，默认应用需要由用户自己选择，因此默认应用为其他程序的扩展名旁会显示 **[未生效]** 标记。点击该标记会直接打开 Windows 的默认应用选择窗口，选择 KPlayer 即可。也可以点击 **打开 Windows 默认应用设置** 打开 Windows 设置，一次性更改。
- 即使把便携版文件夹移到别处，下次启动时关联也会自动对应到新位置。
- 卸载安装版时，KPlayer 注册的所有关联都会恢复原状。

**想把设置恢复到初始状态**
点击设置窗口下方的 **默认值**，所有设置以及快捷键、鼠标操作都会恢复为默认值。文件关联不会改变。

**想根据显卡调整视频输出**
在设置 → **视频** 中选择 **硬件解码**（自动(安全) / 自动 / 不使用）、**输出驱动**、**图形 API**（自动 / Direct3D 11 / OpenGL / Vulkan）、**画面同步**、**放大算法**、**反交错**。大多数情况下默认值最好。此卡片中的设置在重新启动 KPlayer 后生效。

设置和播放列表保存在与可执行文件相同的文件夹中，因此整体移动便携版文件夹时，它们也会一起带走。

界面语言跟随 Windows 显示语言（韩语、英语、日语、中文、俄语、意大利语、法语、西班牙语、阿拉伯语 — 其他语言显示为英语）。

## 系统要求

- Windows 10 或 Windows 11，**64 位**
- 无需另外安装解码器或组件。
- 仅在检查新版本提示时使用网络。

## 更新

KPlayer **不会**自动更新。启动时会检查是否有新版本并弹出提示窗口；选择获取后会打开下载页面并关闭程序。新版本经内部验证后手动发布，并在 [KPlayer 页面](https://kilho.net/kplayer)公告。请参阅[更新政策说明](https://en.kilho.net/archives/notice/2940)。

## 从源码构建

源码公开于 [github.com/newkilho/KPlayer](https://github.com/newkilho/KPlayer)。使用 [Lazarus](https://www.lazarus-ide.org/) 4.x（FPC 3.2.2，Win64）构建，需要以下内容：

- [LibMPVDelphi](https://github.com/nbuyer/libmpvdelphi) — libmpv 绑定单元
- `laz.virtualtreeview_package` — Lazarus 自带的 Virtual Treeview 包
- 运行时 `KPlayer.exe` 旁需要有 `libmpv-2.dll`

把 `Const-sample.inc` 复制为 `Const.inc` 后，用 `lazbuild KPlayer.lpi` 构建。不过，负责更新检查、翻译等功能的公共库（klib）位于仓库之外，因此仅凭仓库无法生成可执行文件。
